# GBoard Personal Dictionary for Pokémon
Personal dictionary for GBoard containing the names of all Pokémon using their national Pokédex number as the shortcut.

# Usage
1. Open the Pokemon Dictionaries Folder
2. Download the file with the language of your choise
3. Navigate to GBoard Settings > Dictionary > Personal Dictionary > All languages (if you have more than 1 language) > 3-dots menu > Import
4. Select the txt file from wherever you saved them
5. Done!
   
# To remove these imported discionaries
The best way I found was deleting the gboard data 
Warning it will also reset your Gboard settings and languages to default
To do:
1. Settings > Apps > (All apps) > Gboard > Clear data > Clear all data
2. Re-enter the settings you had previously
